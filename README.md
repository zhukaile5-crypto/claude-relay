# Claude Relay

一套自建的网页版 Claude：把一台 Windows 电脑上已经登录的 Claude Code（以及 Gemini 的命令行）包成一个网站，在手机、浏览器或桌面端里像用聊天应用一样用它，而模型的文件和命令操作被关在按账号隔离的执行层里。

这是一个个人项目，不是通用产品。仓库里是 2026-11-23 的一份代码快照，人名、域名、本机路径都已换成占位内容，所以**拿下来不能直接运行**：需要自己的 `config.json`、运行环境和域名。放出来是为了分享做法。

## 组成

| 目录 / 文件 | 是什么 |
|---|---|
| `server.js` | Node 单文件服务：登录、对话、项目、记忆、文件、额度显示、模型进程的启动和事件流 |
| `public/` | 单文件页面（`index.html`），手机、浏览器、桌面端共用；PWA 清单和 Service Worker |
| `isolation/` | 隔离执行层：模型的读写文件、运行命令、TeX 编译、语音都经过它，按账号限制在各自的工作文件夹里，不能联网、不能碰桌面 |
| `desktop/` | Electron 桌面端：加载同一个网站，另外提供「关联文件夹」——让模型读、改用户自己电脑上的文件夹 |
| `harmony-app/` | 鸿蒙（HarmonyOS NEXT）手机端：ArkWeb 套壳，处理登录保持、上传下载、麦克风、返回手势 |
| `tools/` | 上线和维护：隔离检查、完整边界验收、日常重新验收、固定程序的自动升级、看门狗 |
| `tests/` | 单元测试、源码回归测试和验收探针（`tests/acceptance/`） |
| `wake-worker/`、`maintenance-mail-worker/` | 两个 Cloudflare Worker：远程叫醒睡眠中的电脑、发维护通知邮件 |

## 主要功能

- **多模型**：Claude（本机订阅）和 Gemini（agy 命令行）；对话中途可以换模型接着做，也可以请另一家的模型复核上一条回答。
- **聊天 / 工作两种对话**：聊天碰不到用户电脑上的文件；工作可以关联文件夹。新对话里选，发出第一条后锁定，由服务器强制。
- **关联文件夹**（桌面端）：授权后整个文件夹传到服务器上的副本，模型改副本，改动按四档权限（只读 / 每次问我 / 自动审查 / 全部允许）写回；写回前备份，删除进回收站，可撤销；每个文件留版本历史。
- **项目和两层记忆**：项目有自己的说明、资料和记忆；账号另有一份长期记忆。
- **文档类能力**：PDF、Word、PPT、Excel、LaTeX、OCR、语音转写、做图做视频，通过一组只读的 skill 和受保护的 Python 环境提供。
- **远程访问**：经 Cloudflare 隧道暴露到公网；电脑睡着时页面显示提示并可远程叫醒。

## 隔离和验收

这个项目里花力气最多的是「模型不能越界」：

- 订阅认证留在主机上的编排进程里，模型拿不到；模型的工具调用全部转给按账号隔离的执行器。
- `tools/check-isolation.cjs` 对服务源码、隔离实现、运行环境和固定程序约五千个文件做指纹核对，和验收记录不一致时服务进入受限模式（只能登录和看历史），不会退回无隔离运行。
- 改了隔离、运行环境或核对代码，要跑 `tools/full-acceptance.cjs` 的完整边界验收：文件系统、网络、桌面、取消、父进程退出等探针，加上用真实模型跑的账号隔离、模型接力和端到端，再加一次独立审查，全部通过才写新的验收记录。
- 只改 `server.js` 时走 `tools/maintain.cjs deploy --restart` 的日常重新验收。

## 运行需要什么（概要）

Windows 11、Node.js 24、已登录的 Claude Code；可选 agy（Gemini）。隔离层依赖一份单独准备的只读运行环境（Python、TeX Live、LibreOffice、ffmpeg 等）和它的清单文件，这部分不在仓库里。`config.json`（账号、密钥、路径）、`data/`、`logs/` 也不在仓库里。

## 测试

```powershell
node tests/run.cjs
```

只读源码和内存里的模拟对象，不调用真实模型、不碰正在运行的服务。验收探针（`tests/acceptance/`）会调用真实模型，需要完整的运行环境。
